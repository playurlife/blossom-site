# Blossom Business – React screen

## Run it
1. Install Node.js (from nodejs.org) if you haven't.
2. Open this folder in VS Code, then open the terminal (View → Terminal).
3. Run `npm install` (once, downloads React and Vite).
4. Run `npm run dev` and open the link it prints (usually http://localhost:5173).

Edit any file and save – the browser updates instantly.

## Where things are
- `src/App.jsx` – stacks the page sections in order
- `src/components/Header.jsx` – logo, contact bar, navigation menu
- `src/components/Hero.jsx` – banner, headline, buttons, slider arrows
- `src/components/SettingsButton.jsx` – the gear tab on the left
- `src/components/Icons.jsx` – small SVG icons
- `src/styles.css` – all styling; colors are at the top as variables

## Add your photo
Put your image in the `public` folder as `hero-1.jpg` (and `hero-2.jpg` for slide 2).
